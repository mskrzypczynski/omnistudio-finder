OmniStudio Finder settings

Designer

Where records live and which designer an org opens are two different things — an org can keep data in the standard objects while an admin has switched on the Managed Package Designer. OmniStudio Finder detects them separately. Change this if it picks wrong.

Hold Ctrl (⌘ on macOS) while clicking to do the opposite just once. Hold Shift to open the plain record page instead of the designer.

Designer links

These are built in and correct for current orgs, so you shouldn't need to touch them. Override one only if Salesforce changes a builder URL in a later release. Leave a box empty to use the built-in link shown in grey.

Placeholders: {id} {name} {type} {subtype} {language} {version} {sobject}, plus {ns} for the package namespace, {vfhost} for the Visualforce host, and {now} for a cache-busting timestamp. A value starting with / is resolved against whichever org you're browsing.
