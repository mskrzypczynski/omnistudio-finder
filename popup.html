Finding things

Type to filter on name, type, subtype, language or author. Every word has to match, in any order, so case create finds "Create Case". OmniScripts and Integration Procedures also match their key, Type_SubType_Language (or Type_SubType), as it appears in logs and element names, so you can paste one straight in; hover a row's type line to see it. The buttons above narrow by asset type, and Active only hides anything with no active version.

Opening things

Open v3 opens the active version — that's the one you want nearly always. Click a version chip instead to open that specific version. Shift-click either one to open the plain Salesforce record page rather than the designer. Clicking the row itself only selects it, so a stray click can't launch a designer.

Navigation bar

Settings can pin a Lightning app, so pages open with that app's navigation bar rather than whichever app you were last in. How far it reaches depends on where the designer lives: anything under /lightning/ can carry it, nothing else can.

On core OmniStudio that means record pages only. All four builders sit at /builder_omnistudio/…, outside the Lightning shell, and Salesforce draws no navigation bar around them — the same as Flow Builder.

On the managed packages, FlexCards and the OmniScript designer carry the app in the URL. The Integration Procedure and DataRaptor designers are Visualforce pages that can't, so those switch to the app first and then follow through — you'll see one extra page load on the way.

Which org, which designer

The org comes from your current tab, so switching orgs is just switching tabs. The designer is detected separately, because an org can store records in the standard objects while running the managed package designers. The line under the search box names the one in use; Settings lets you force either.

When something goes wrong

No session found — log in to the org in this browser, then reopen.
Session rejected — refresh the Salesforce tab. If it persists, your profile may not have API Enabled.
Wrong designer opens — switch it in Settings.
Results look stale — press Reload. The list is read fresh each time you open the popup, so this only matters if something changed while it was already open.
